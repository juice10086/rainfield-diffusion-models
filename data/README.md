# Data preparation

This folder contains the scripts used to prepare OpenMRG rain-rate arrays and CML experiment settings ([Link to data and checkpoints](https://drive.google.com/file/d/15NGJAnmVsSbYWfnOcqfITMGDegBW0nBH/view?usp=share_link)).

The prepared data release has the following structure:

```text
data/
├── train_rain_rate_f4.npy
├── test_rain_rate_f4.npy
├── train_log_rain_rate_f4.npy
├── test_log_rain_rate_f4.npy
├── cml_coordinates_ls-all.npy
├── cml_metadata.npz
├── cst_a_power_b_openmrg.pt
├── exp_settings/
    ├── simulated_seed_321_n_links_100_max_len_5.pt
    ├── simulated_seed_321_n_links_25_max_len_20.pt
    └── selected_nnz_test_idx.npy
└── checkpoints
    ├── ...
```

Transformations:

- `train_rain_rate_f4.npy`, `test_rain_rate_f4.npy`: cropped rain-rate fields split into train/test sets.
- `train_log_rain_rate_f4.npy`, `test_log_rain_rate_f4.npy`: same split after `log1p(rain_rate) / log(10)`.
- `cml_metadata.npz`: CML metadata extracted from the original OpenMRG `data/cml/cml_metadata.csv`.
- `cml_coordinates_ls-all.npy`: CML coordinates extracted from the same CSV and transformed to the radar `48 x 36` grid.
- `cst_a_power_b_openmrg.pt`: power-law constants computed from `cml_metadata.npz`.
- `exp_settings/simulated_seed_321_n_links_100_max_len_5.pt`: simulated many-short CML setting.
- `exp_settings/simulated_seed_321_n_links_25_max_len_20.pt`: simulated few-long CML setting.
- `exp_settings/selected_nnz_test_idx.npy`: selected non-empty test-field indices.

`cml_metadata.npz` and `cml_coordinates_ls-all.npy` are not generated by the scripts below.

## Raw rain-rate input

Create `data/rain_rate.npy` from OpenMRG with:

```python
import numpy as np
import pynncml as pnc

link_set, ps, rd = pnc.datasets.load_open_mrg(
    data_path="./data/",
    rain_gauge_time_base=300,
)

np.save("data/rain_rate.npy", rd.radar_array.astype(np.float32))
```

This download and conversion step can take a while.

## Reproduce the prepared files

Run commands from the repository root.

Preprocess rain rates:

```bash
python data/preprocess.py \
  --input data/rain_rate.npy \
  --output-dir data \
  --save both
```

This crops rain fields to `48 x 36`, keeps the last one fifth of samples as the test split, and saves both raw and log-transformed arrays. The log transform is `log1p(rain_rate) / log(10)`.

Compute CML power-law constants:

```bash
python data/openmrg_cml.py \
  --metadata-path data/cml_metadata.npz \
  --output-dir data
```

Generate the two simulated CML settings:

```bash
python data/generate_simulated_cml.py \
  --n-links 100 \
  --max-len 5 \
  --seed 321 \
  --output-dir data/exp_settings

python data/generate_simulated_cml.py \
  --n-links 25 \
  --max-len 20 \
  --seed 321 \
  --output-dir data/exp_settings
```

Select non-empty test-field indices:

```bash
python data/select_idx_links.py \
  --test-data-path data/test_rain_rate_f4.npy \
  --output-dir data/exp_settings \
  --output-name selected_nnz_test_idx.npy \
  --n-samples 1000 \
  --seed 1234
```

## Custom output directories

Every script that writes files accepts `--output-dir`. For example:

```bash
python data/preprocess.py --output-dir /tmp/rain-data
python data/openmrg_cml.py --output-dir /tmp/rain-data
python data/generate_simulated_cml.py --n-links 100 --max-len 5 --output-dir /tmp/rain-data/exp_settings
python data/select_idx_links.py --output-dir /tmp/rain-data/exp_settings
```

When using a custom directory, pass the matching generated paths to downstream configs and scripts.

## Important defaults

- Rain-rate input: `data/rain_rate.npy`
- Preprocessed output directory: `data/`
- Crop size: `48 x 36`
- Test split: last `20%` of samples
- Simulated CML output directory: `data/exp_settings/`
- Simulated CML seed: `321`
- Selected-index output directory: `data/exp_settings/`
- Selected-index seed: `1234`
